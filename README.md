# Dental-Clinic-OS
**منظومة تشغيل وإدارة متكاملة لعيادات ومراكز طب الأسنان**

**Dental-Clinic-OS** هو نظام متكامل مبني بلغة Python ومجهّز كنسخة سطح مكتب مستقلة قابلة للتشغيل على Windows، صُمّم لهندسة وأتمتة الدورة التشغيلية والسريرية والمحاسبية الكاملة داخل عيادات ومراكز طب الأسنان. يجمع النظام بين سهولة الاستخدام للطاقم الطبي والإداري، والدقة المحاسبية في تتبع التدفقات النقدية، الفواتير، ذمم المرضى، المشتريات، المختبرات، ومعاملات الموظفين، مع دعم التنسيقات الإقليمية للغة العربية، هوية بصرية موحدة، وملف إعدادات مخصص للعيادة.

---

## أبرز المزايا والقدرات الهندسية

* **جاهزية تشغيل مباشرة:** يتضمن حزمة تشغيل مجمّعة على Windows دون الحاجة لتعقيدات الإعداد على أجهزة التشغيل.
* **فصل معماري منظم:** يفصل بين طبقة منطق الأعمال والوصول للبيانات (`backend`) عبر وحدات مستقلة (`Repositories`)، وطبقة واجهات المستخدم والهوية البصرية (`ui` و`assets`).
* **منظومة محاسبية ومالية متكاملة:** يغطي الفواتير، حسابات المرضى، كشوفات الحساب، الصندوق اليومي، الخزينة، المصروفات، المشتريات، الموردين، ومدفوعات المختبرات.
* **متابعة سريرية ومخبرية شاملة:** ينظّم بيانات المرضى، المواعيد، الزيارات العلاجية، العلاجات، والمختبرات وأوامر العمل المرتبطة بها.
* **إدارة الموارد البشرية والحوكمة:** يشمل إدارة الموظفين ومعاملاتهم المالية، نظام تسجيل الدخول، إعدادات العيادة (`clinic_config.json`)، والتقارير.
* **حماية البيانات والاستمرارية:** يدعم النسخ الاحتياطي التلقائي لقاعدة البيانات بصيغة SQL لحماية السجلات.

---

## الوحدات الأساسية للنظام

### 1. المرضى والمواعيد والزيارات العلاجية
* **المرضى (`Patients`):** إدارة سجل المرضى وحساباتهم وأرصدتهم.
* **المواعيد (`Appointments`):** جدولة وتنظيم مواعيد المراجعين.
* **الزيارات والعلاجات (`Patient Visits & Treatments`):** توثيق الزيارات والإجراءات العلاجية المقدمة.

### 2. المختبرات الخارجية
* **المختبرات (`Labs`):** إدارة بيانات المختبرات المتعاقد معها.
* **أوامر العمل المخبرية (`Lab Orders`):** متابعة الطلبات والحالات المرسلة للمختبرات.
* **مدفوعات المختبرات (`Lab Payments`):** تسجيل وضبط المستحقات والدفعات المالية للمختبرات.

### 3. النظام المالي والمحاسبي
* **الفواتير وحسابات المرضى (`Invoices & Patient Accounts`):** إصدار الفواتير ومتابعة أرصدة وحسابات المرضى.
* **الخزينة والصندوق اليومي (`Treasury & Daily Cash`):** متابعة حركة النقد والصندوق اليومي والخزينة.
* **كشوفات الحساب (`Statements`):** إعداد ومراجعة كشوفات الحساب.
* **المصروفات (`Expenses`):** تسجيل ومتابعة مصروفات العيادة.

### 4. المشتريات والموردون والموظفون
* **المشتريات والموردون (`Purchases & Suppliers`):** إدارة عمليات الشراء وحسابات الموردين.
* **الموظفون ومعاملاتهم (`Staff & Employee Transactions`):** إدارة بيانات الموظفين ومعاملاتهم المالية.

### 5. الأمان والتقارير والنسخ الاحتياطي
* **المصادقة والإعدادات (`Authentication & Settings`):** تسجيل الدخول وضبط إعدادات النظام والعيادة.
* **التقارير (`Reports`):** استخراج التقارير التشغيلية والمالية.
* **النسخ الاحتياطي (`Database Backups`):** حفظ نسخ احتياطية تلقائية لقاعدة البيانات بصيغة SQL.
