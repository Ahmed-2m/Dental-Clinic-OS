# Dental-Clinic-OS
**منظومة تشغيل وإدارة متكاملة لعيادات ومراكز طب الأسنان (Desktop ERP & Clinical Management System)**

**Dental-Clinic-OS** هو نظام سطح مكتب متكامل مبني بلغة **Python** وقاعدة بيانات **MySQL**، صُمّم لهندسة وأتمتة الدورة التشغيلية والسريرية والمحاسبية الكاملة داخل عيادات ومراكز طب الأسنان. يجمع النظام بين سهولة الاستخدام للطاقم الطبي والإداري، والدقة المحاسبية في تتبع التدفقات النقدية، الفواتير، ذمم المرضى، المشتريات، المختبرات، ومعاملات الموظفين، مع واجهة عربية متكاملة، سمات بصرية قابلة للتخصيص، وملف إعدادات مستقل لكل عيادة.

---

## القيمة التشغيلية والتجارية (لأصحاب العيادات والمراكز الطبية)

* **إدارة شاملة من مكان واحد:** توحيد ملفات المرضى، المواعيد، الزيارات العلاجية، الفواتير، والمختبرات في واجهة واحدة سريعة وواضحة.
* **ضبط مالي ومحاسبي دقيق:** متابعة لحظية للصندوق اليومي، الخزينة، ذمم المرضى، المصروفات، ومستحقات الموردين والمختبرات دون تسرب مالي.
* **تخصيص سريع لهوية العيادة:** إمكانية ضبط اسم العيادة وبيانات التواصل والمظهر البصري (`Dark / Light`) مباشرة عبر ملف الإعدادات `clinic_config.json`.
* **أمان واستمرارية البيانات:** نظام صلاحيات وتسجيل دخول للموظفين، مع دعم النسخ الاحتياطي التلقائي لقاعدة البيانات بصيغة SQL لحماية السجلات.
* **جاهزية للنشر التجاري:** قابل للتجميع كنسخة تشغيل مستقلة على نظام Windows (عبر `main.spec`) لتسليمه وتشغيله لدى العملاء بسهولة.

---

## المزايا والقدرات الهندسية (للمبرمجين وجهات التوظيف)

* **معمارية طبقية نظيفة (Layered & Repository Pattern):** فصل واضح بين طبقة منطق الأعمال والوصول للبيانات (`backend/`) عبر 19 وحدة مستودع مستقلة (`Repositories`)، وطبقة واجهات المستخدم (`ui/`)، والهوية البصرية (`assets/`).
* **تكامل مع قاعدة بيانات MySQL:** إدارة مركزية للاتصال وفحص حالة السيرفر (`Health Check`) عبر `backend/database.py` باستخدام `mysql-connector-python` مع دعم الترميز الكامل للغة العربية (`utf8mb4`).
* **تغليف وتوزيع احترافي:** فصل الكود المصدري النظيف في المستودع مع توفير ملف البناء `main.spec` لإنتاج حزم التشغيل التنفيذية عبر PyInstaller.
* **إدارة اعتماديات وتهيئة مرنة:** تعريف واضح للمكتبات الخارجية في `requirements.txt` وفصل إعدادات التشغيل عن الكود المصدري.

## الوحدات الأساسية للنظام

### 1. المرضى والمواعيد والزيارات العلاجية
* **المرضى (`Patients`):** إدارة سجل المرضى وحساباتهم وأرصدتهم.
* **المواعيد (`Appointments`):** جدولة وتنظيم مواعيد المراجعين.
* **الزيارات والعلاجات (`Patient Visits & Treatments`):** توثيق الزيارات والإجراءات العلاجية المقدمة.

### 2. المختبرات الخارجية
* **المختبرات (`Labs`):** إدارة بيانات المختبرات المتعاقد معها.
* **أوامر العمل المخبرية (`Lab Orders`):** متابعة الطلبات والحالات المرسلة للمختبرات.
* **مدفوعات المختبرات (`Lab Payments`):** تسجيل وضبط المستحقات والدفعات المالية للمختبرات.

### 3. النظام المالي والمحاسبي
* **الفواتير وحسابات المرضى (`Invoices & Patient Accounts`):** إصدار الفواتير ومتابعة أرصدة وحسابات المرضى.
* **الخزينة والصندوق اليومي (`Treasury & Daily Cash`):** متابعة حركة النقد والصندوق اليومي والخزينة.
* **كشوفات الحساب (`Statements`):** إعداد ومراجعة كشوفات الحساب.
* **المصروفات (`Expenses`):** تسجيل ومتابعة مصروفات العيادة.

### 4. المشتريات والموردون والموظفون
* **المشتريات والموردون (`Purchases & Suppliers`):** إدارة عمليات الشراء وحسابات الموردين.
* **الموظفون ومعاملاتهم (`Staff & Employee Transactions`):** إدارة بيانات الموظفين ومعاملاتهم المالية.

### 5. الأمان والتقارير والنسخ الاحتياطي
* **المصادقة والإعدادات (`Authentication & Settings`):** تسجيل الدخول وضبط إعدادات النظام والعيادة.
* **التقارير (`Reports`):** استخراج التقارير التشغيلية والمالية.
* **النسخ الاحتياطي (`Database Backups`):** حفظ نسخ احتياطية تلقائية لقاعدة البيانات بصيغة SQL.

## التقنيات المستخدمة

* **لغة البرمجة:** Python
* **قاعدة البيانات:** MySQL (`mysql-connector-python`)
* **معالجة الصور والهوية البصرية:** Pillow (`PIL`)
* **التدويل والتنسيق الإقليمي:** Babel
* **التجميع وبناء نسخة سطح المكتب:** PyInstaller (`main.spec`)
